## 1. 共通表格結構

三張表的寫法都一樣：每個人一個區塊，從上到下依序是

```
第 1 列：成家婚顧(主持團隊/工作人員): | 姓名 | 員工編號: | 編號
第 2 列：表頭 活動/婚宴日期 | 時段 | 地點/廳別 | 宴會名稱 | 品項1 | 費用 | 品項2 | 費用 | 總費用 | 備註 | 應收
第 3 列起：每場一列
最後一場那列：在「應收」欄填這個人的小計
```

| 欄 | 主持／婚企表 | 場控表 |
|---|---|---|
| A | 日期 | 日期 |
| B | 時段（午宴／晚宴／早儀晚宴） | 時段 |
| C | 地點／廳別 | 地點 |
| D | 宴會名稱 | 宴會名稱 |
| E / F | 品項 1／費用（**執行費**） | 品項（場控/音控/管家）／費用 |
| G / H | 品項 2／費用（**業績獎金**） | 備註（編號＋姓名＋**工作時間**） |
| I | 總費用 `=SUM(E:H)` | 流水序號（場次計數） |
| J | 備註（計算過程） | – |
| K | 應收（個人小計） | – |
| L | 流水序號（場次計數，主持表） | – |

## 2. 外發場控費用（2026.06外發場控）

### 2.1 公式

```
單場費用 F = 工作時數 × 時薪  (+ 到府場控 1,000，如果有)
工作時數   = 結束時間 − 開始時間 （用小時算，半小時 = 0.5）
個人應收 H = SUM(該人所有 F)
月總計     = SUM(所有人 H)
```

### 2.2 費率（依 6 月實際資料）

| 項目 | 費率 | 6 月實例 |
|---|---|---|
| 場控（一般） | **200 元/小時** | 宇靜 0930-1600 → `=200*6.5` = 1,300 |
| 場控（資深：A-0027 Eunice、A-0034 明蓁） | **250 元/小時** | Eunice 0830-1530 → `=7*250` = 1,750 |
| 音控（一般） | 200 元/小時 | 尚寬 1030-1500 → `=4.5*200` = 900 |
| 音控（A-0082 加峰） | 250 元/小時 | `=4.5*250` = 1,125 |
| 管家 | 200 元/小時 | Emma 0830-1500 → `=6.5*200` = 1,300 |
| 到府場控／早上迎娶 | **1,000 元/場（固定）** | 謝妧芷「到府場控（1,000/場）」 |
| 到府＋宴客 | 1,000 + 時數×時薪 | 明蓁 `=1000+6*250` = 2,500；EVA `=1000+5.5*200` = 2,100 |

> 「不勞保」只是註記，不改變金額。

### 2.3 建議的 Excel 寫法

在每列多加「開始」「結束」「時薪」「到府費」四欄（例如 J/K/L/M），F 欄改成：

```excel
F = ROUND((K - J) * 24 * L, 0) + M
H(最後一列) = SUM(F起:F迄)
月總計 = SUM(H:H)   ← 範圍要從第一個人的第一列開始
```

## 3. 外發主持費用（2026.06外發主持）

### 3.1 公式

```
單場費用 F = 各品項費用相加（例如 企劃主持+儀式 → =3000+5000）
業績     H = 幫公司賣出案子的業績獎金（只有部分人有，例如詩雲）
總費用   I = SUM(E:H) = F + H

月總計     = SUM(所有人 K)
```

## 4. 婚企獎金（2026.06主持婚企）

婚企獎金 = **執行費（E/F）** + **業績獎金（G/H）**。

```
I（每場） = SUM(E:H) = 執行費 + 業績
K（每人） = SUM(該人所有 I)
月總計     = SUM(所有人 K) = 482,331
```

### 4.2 業績獎金（自己賣出的案子）

**(A) 業務獎金：每個賣出的服務項目固定 500 元**

| 賣出的組合 | 獎金 | 備註寫法範例 |
|---|---:|---|
| 主持／總召／儀式／指定（單項） | 500 | `業務-念純/主持 $12190-$2000(Leo)-$1500=$8690-$500=$8190` |
| 文定＋迎娶（2 項） | 1,000 | `業務-念純/文定迎娶 $12572-$5000(AM)=$7576-$1000=$6576` |
| 主＋召＋留（3 項） | 1,500 | `業務-念純/主+召+留 $16001-$2500-$2000-$200=$11301-$1500=$9801` |

**(B) 加購廠商項目：淨額的 10%**

```excel
業績 = ROUND(淨額 * 10%, 0)
淨額 = 未稅售價                      （布置、婚攝、婚錄、婚紗攝影、西服、媽媽裝、新秘、喜帖、影片、硬體、電視牆、拍拍印、樂團、KAHOO、儀式備品租借）
淨額 = 未稅售價 − 成本               （儀式備品販售、宜時婚錄、點心吧、line@、嘉廬證婚專案）
淨額 = 音控售價 − 1,500 場控成本     （音控）
```

範例：
- 布置 952 × 10% = 95
- 儀式備品販售 (1,524 − 1,300) × 10% = 22
- 音控 (3,429 − 1,500) × 10% = 193
- 嘉廬證婚專案 (34,362 − 16,300) × 10% = 1,806

### 4.3 備註欄的公司毛利寫法（給業務看的）

備註欄記錄每一案公司賺多少，格式是：

```
未稅售價 − 執行人員費用(姓名) − 場控成本 1,500 − 留聲機 200 = 小計 − 業務獎金 = 公司毛利
```

- **未稅售價 = 含稅價 ÷ 1.05**（例如 8,800 → 8,381；16,800 → 16,001；12,000 → 11,429；6,300 → 6,000）
- 場控成本 1,500：有派場控的指定主持案才扣
- 留聲機 200：有「留」（留聲機）的方案才扣

## 6. 建議的標準公式（每月複製用）

```excel
' ── 場控表 ──
F(每場)   = ROUND((結束-開始)*24*時薪, 0) + 到府費
H(個人)   = SUM(F第一場:F最後一場)
月總計     = SUM(H4:H最後一列)
場次       = COUNT(F4:F最後一列)

' ── 外發主持表 ──
F(每場)   = 品項費加總
I(每場)   = SUM(E:H)               ' 文字欄會被 SUM 忽略
K(個人)   = SUM(I第一場:I最後一場)
月總計     = SUM(K4:K最後一列)

' ── 婚企表 ──
H(業績)   = 500*業務項數 + ROUND(加購淨額*10%,0) ...
I(每場)   = SUM(E:H)
K(個人)   = SUM(I第一場:I最後一場)
月總計     = SUM(K4:K最後一列)

' ── 月份彙總 (23-2026外發主持 by月份) ──
當月合計   = 主持費用 + 場控費用 + 婚企獎金
```
